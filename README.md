# Spawn Wandering Trader

Mod adds a single command, `/spawntrader`

It takes no arguments and force-spawns a Wandering Trader by repeatedly running the game's own spawn routine, so the trader (llamas, despawn timer, home position, biome and space checks) is the same as a naturally spawned one.

- Requires permission level 2 (operators, command blocks, console). Other players cannot see or run it.
- Server-side logic only; no Fabric API is needed.
